# ShelterSoul Frontend

React frontend for the ShelterSoul pet adoption platform.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The app will run on `http://localhost:3000`

## Build

```bash
npm run build
```

## Features

- User authentication (Login/Register)
- Pet browsing and search
- Pet management for shelters
- Adoption request system
- Favorites functionality
- Admin dashboard

## Tech Stack

- React 18
- React Router DOM
- Axios
- Vite
- CSS3
